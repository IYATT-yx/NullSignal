# NullSignal 息屏工具  

2026/10/3  
我有时候会用自己的笔记本电脑跑任务，需要保持在后台运行，但是不需要亮屏（避免消耗屏幕寿命和节约用电）。我是在电源计划中设置了 3 分钟无操作自动关闭屏幕的，但是有时候有些程序会阻止息屏（比如百度网盘、RustDesk），结果就是一直亮着。  
下午我在思考有什么合适的方案实现息屏，试过多个三方软件，我自己编写程序也尝试了多种方案，总是会直接触发睡眠而不是息屏。我怀疑这是 BIOS 硬件层面限制了，把息屏和睡眠绑定在一起了，软件上没法解决这个问题。  
我就想到 RustDesk 有一种隐私模式是通过把视频信号切换到虚拟显示器让物理显示器不显示来实现的，因此我也采用了这种方案尝试，目前看来是成功的。  

2026/10/25  
我根据网友的建议，增加托盘图标（并支持设置开机自启动），同时增加了快捷键。

## 测试环境

* Windows 11 25H2  
* Python 3.14.5
